# Licensing And Attribution

DoxieOS is licensed under the Apache License, Version 2.0.

This project also ships a `NOTICE` file. Keep that file with redistributed
source, documentation, packages, or generated third-party notice surfaces.

## Why Apache-2.0

Apache-2.0 fits this project because it is permissive while still preserving
important attribution and patent protections.

Compared with MIT, Apache-2.0 is more explicit about:

- retaining notices in redistributed source forms;
- carrying readable attribution notices from `NOTICE`;
- marking modified files;
- contributor patent grants.

This is aligned with the intended use: DoxieOS can be used freely, including in
commercial or internal environments, while preserving visible attribution to the
project.

## What Users Should Preserve

Redistributors should keep:

- `LICENSE`;
- `NOTICE`;
- copyright and attribution notices;
- modification notices when files are changed.

## Attribution Request

If DoxieOS influences or powers your internal agent platform, product fork, or
automation layer, keep an attribution notice visible in your repository,
documentation, package notices, or product third-party notices area.

organization, review the license text and ask qualified counsel.
