# DoxieOS 1.3.1

DoxieOS 1.3.1 is a focused release polish pass. It tightens the shell around
the first configurable language support and removes the small layout rough edges
that showed up after the 1.3.0 design-system pass.

## What Changed

- Settings now includes an application language selector.
- Portuguese and Spanish translations now cover the main navigation, dashboard, workspaces, consoles, agents, workflows, libraries, history, settings, MCP servers, Doxie catalogs, storage paths, and workflow execution guidance.
- The footer is slimmer and simpler, with the current release version anchored on the right.
- Release notes now live behind the version action in the footer instead of competing with the main shell navigation.
- The side navigation drawer now opens and closes more smoothly in mini mode, with a calmer hover transition and less icon/text jitter.
- Navigation labels have more vertical room so descenders and accented characters render cleanly.

## Notes

This release keeps the 1.3 design direction intact and focuses on product
readiness: clearer localization, less visual noise, and a smoother shell for
daily use.
