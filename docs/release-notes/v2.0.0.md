# DoxieOS Desktop 2.0.0

DoxieOS runs as a desktop application built with Electron, Node.js, and React.
The workbench brings the catalog, workflow engine, live consoles, builders, and
run history together behind a local IPC bridge.

The interface keeps the familiar dark navigation and terracotta accents. Bordered
panels, clearer page hierarchy, and reorganized run and file details make it
easier to scan activity and find the next action.

The build verifies npm registry sources, locked SHA-512 digests, and registry
signatures before running dependency setup scripts. The audit fails on high or
critical findings, and only the Electron runtime and terminal binding run
explicit dependency setup. Windows builds include a portable ZIP.

Open the original Doxie workbench folder to reuse its catalogs, workspaces, and
artifacts. The desktop app can use the existing SQLite database and read 1.x
transfer archives. [Upgrade guide](../operations.md#upgrade-from-doxieos-1x)
