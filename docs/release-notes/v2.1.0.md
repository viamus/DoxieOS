# DoxieOS 2.1.0 — Brain

Brain is a shared knowledge base, independent of workspaces. Search
memories, explore evidence relationships, and inspect provenance and learned
parameters from the Brain page. The harness records verified learnings in
every execution. Revisions preserve
earlier records and link updated evidence.

Import selected Codex and Claude Code memory files explicitly after previewing
their contents. There is no automatic scanning or import. Originals stay intact.
Imports deduplicate knowledge and retain
source paths. Credentials and conversation logs are excluded. Optional local
multilingual embeddings add search by meaning and weighted inferred connections.
LadybugDB stores the local graph and vectors; the original knowledge database
is preserved after migration. Review dates mark stale memories for revalidation
without deleting history.

Brain now extracts entities and typed parameters locally from explicit source
facts, retaining exact evidence and shared provenance. Unexpected connections
explores indirect graph paths as hypotheses. Clear Brain provides an explicit
confirmed reset while preserving provider originals and the installed model.
The dashboard shows Brain with knowledge counts, without counting the Brain
itself as a catalog item.

Every agent, model step, builder and console has the mandatory Brain connector.
Its native tools retrieve knowledge, inspect weighted relationships, and review
obsolete memories. The Brain workflow connector queries knowledge or publishes a verified learning
without a workspace mount. Manual Markdown enters through the separate
Workspace Memory connector. Workspaces hold execution inputs and outputs;
legacy generated context is removed while manually authored files are kept.
