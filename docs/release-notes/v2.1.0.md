# DoxieOS 2.1.0 — Shared library

Libraries now form a shared knowledge base, independent of workspaces. Search
memories, explore evidence relationships, and inspect provenance and learned
parameters from the Library page. The harness feeds knowledge autonomously in
every execution; the page has no manual registration forms. Revisions preserve
earlier records and link updated evidence.

The harness synchronizes recognized Codex and Claude Code memory files in the
background without changing their originals. Imports deduplicate knowledge and retain
source paths. Credentials and conversation logs are excluded. Optional local
multilingual embeddings add search by meaning to the built-in text index.

Agents and workflows can read and feed the library through native memory tools.
The Library connector queries knowledge or publishes a verified learning
without a workspace mount. Manual Markdown enters through the separate
Workspace Memory connector. Workspaces hold execution inputs and outputs;
legacy generated context is removed while manually authored files are kept.

See the [library guide](../library-memory.md) and
[upgrade notes](../operations.md#upgrade-from-20).
