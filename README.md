# DoxieOS Public

DoxieOS Public is the open workspace for the DoxieOS project.

This repository is starting from a clean slate. The first goal is to establish a public-facing foundation that can grow into code, documentation, experiments, and release artifacts without losing the thread of decisions along the way.

## Status

Initial repository setup in progress.

- `docs/` - project notes, decisions, and episode logs.
