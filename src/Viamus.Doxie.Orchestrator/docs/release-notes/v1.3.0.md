# DoxieOS 1.3.0

DoxieOS 1.3.0 is the first productivity and design-system pass for DoxieOS.
The goal is simple: make the product feel calmer, sharper, and more useful during
real agent work without adding visual noise.

## What Changed

- DoxieOS is now dark-only, with the shell and high-traffic pages tuned around a single black-first design direction.
- The main navigation, dashboard, agents, workflows, libraries, and settings surfaces were tightened for denser, more professional day-to-day use.
- Library pages now put discovery and reuse first, with clearer hierarchy, cleaner catalog presentation, and stronger scanning behavior.
- Settings catalog management is simpler: catalog actions moved into the catalog list, duplicate edit cards were removed, and changes persist automatically.
- Workflow detail and editor previews now use a modern dark graph canvas with subtle grid, cleaner node cards, better status colors, curved edges, and loop containers.
- Workflow graph nodes can be dragged to rearrange the canvas; saved workflows keep the adjusted positions.
- Right-clicking an agent node in the workflow graph opens a compact contextual menu with a direct Open Agent action.

## Notes

This release focuses on product feel, information hierarchy, and workflow
ergonomics. The next line can move deeper into backend capabilities from a
stable 1.3 baseline.
